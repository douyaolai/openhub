# 儿童英语动画短片

## 一句话摘要
> 一个 Claude Code skill：输入句型、画风与配乐，自动产出一集约两分半、1920×1080 的儿童英语启蒙动画——台词卡在同一节拍上，口型跟着配音走，还专门留拍等孩子开口。

## 核心分析与要点

- **核心内容**：`kids-english-video` 是 `xiaobei-skills` 仓库下的一个 skill，面向 3–6 岁孩子的英语启蒙。一集的结构是固定的教学法：片头 → 3–4 轮"Bobo 问动物答、老师念单词、单词卡弹出、领念 3 遍 + 齐念 3 遍" → 动物反问 Bobo（先 No 后被说服变 Yes，顺带练否定）→ 跟读环节留 3 拍空白等孩子开口 → 片尾 Bye-bye。示范集《Do You Like Carrots?》约 139 秒。

- **关键亮点 / 结论**：
  - **教学法被拆成了可执行的流水线**：每轮固定换一个单词 + 一个动物，句型反复但不重复场景；跟读环节"留 3 拍空白 + 画面出节拍点"是真正为低龄儿童设计的交互，而不是把成人课程配音搬过来。
  - **节奏是硬约束**：所有台词卡在同一个节拍上（默认 100 BPM），伴奏也用同一节拍；口型按配音响度逐帧切换——这两条决定了成片"像动画"而不是"像 PPT 配音"。
  - **素材规模可观**：9 个代码绘制的场景（草地、海边、雪地、夜晚、森林、厨房、卧室、游乐场、海底）、6 种转场（地图、小火车、滑梯、泡泡、开门、翻页，各配音效）、4 个主角 + 6 个客串动物 + 一个猫头鹰老师；5 种画风（扁平、蜡笔、剪纸、黏土、水彩）与 5 种配乐（尤克里里、音乐盒、玩具进行曲、8-bit、无）。
  - **工具链分工清楚**：Codex 生图（品红底，再脚本切图去边统一身高）→ Fish Audio 配音（按音色与文字缓存）→ Canvas 逐帧 + Playwright 无头浏览器分段并行渲染 → Python 合成音效与伴奏 → FFmpeg 混音（-16 LUFS）。
  - **坑写得很实在**：配音脚本 `fishvoice.py` 读 API key 的函数是从另一个 skill（`manim-explainer-video`）导入的，**那个 skill 不在本仓库**，没装就得改成直接读环境变量；另外生图脚本用了 zsh，所以限定 macOS。
  - **性能有实测数字**：扁平风整集约 70 秒渲完，其他画风约 8–10 分钟。

- **适用场景 / 启发**：
  - 想给孩子做"按自家孩子兴趣定制"的英语动画（换句型、换动物、换画风）比找现成视频更灵活；跑通 `--example` 示范集就能看到完整效果。
  - 对做 Agent Skill 的人，这是一个"skill 不只是提示词，而是整套素材 + 渲染管线 + 素材库约定"的样本：`SKILL.md` 管流程、`references/` 管格式规范、`template/` 放可复用素材。
  - 使用前注意三点：其一，环境是 macOS + Python 3.12 虚拟环境 + FFmpeg + Node（Codex 需登录）+ Fish Audio API key，门槛不低；其二，仓库**未声明开源许可证**（GitHub 元数据为空），字体为 SIL OFL，二次分发前需确认；其三，成片质量依赖生图与 TTS 的额度与网络。

**它是什么**

> `kids-english-video` 是一个 Claude Code skill，用来做给 3–6 岁孩子看的英语启蒙动画短片。横屏 1920×1080，一集两三分钟：一个句型反复问答、单词卡、领念跟念、留空拍让孩子开口答、片尾再见。

**节奏与口型**

> 所有台词都卡在同一个节拍上（默认 100 BPM），伴奏也用这个节拍。口型按配音响度逐帧切换。

**场景与画风**

> 9 个代码画的场景，每轮换一个地方：草地、海边、雪地、夜晚、森林、厨房、卧室、游乐场、海底。

> 画风五选一：`flat` 扁平矢量、`crayon` 蜡笔手绘、`paper` 剪纸拼贴、`clay` 3D 黏土、`watercolor` 水彩绘本。

**素材与工具链**

> 角色和物品图：Codex 生图，品红底，再用脚本切图、去边、统一身高、按下半身对齐

> 混音：FFmpeg，响度 -16 LUFS

**已知依赖坑**

> 注意：配音脚本 `template/fishvoice.py` 读 API key 的函数是从 `manim-explainer-video` skill 导入的（`~/.claude/skills/manim-explainer-video/scripts/fish_tts.py`），那个 skill 不在本仓库里。没有装它的话，把 `fishvoice.py` 里的 `api_key(...)` 换成直接读环境变量即可。

**渲染耗时**

> 成片在 `out/成片.mp4`，另有不带伴奏的 `out/成片_无背景音乐.mp4`。扁平风整集约 70 秒渲完，其他画风约 8–10 分钟。
