# WordLink词汇图谱

## 一句话摘要
> 把「背单词」换成「看词的关系网」：用 32.6 万条带类型的中英词链（同义、近义、词形、易混拼写）给每个词画出邻居图，再在图上挂测验、分级阅读与 AI 家教——外加一套把复习词写成 CEFR 分级故事的小模型微调流水线。

## 核心分析与要点

- **核心内容**：一个开源的英语词汇工作台。右侧面板是当前词的**关系图**：颜色区分关系类型（同义／近义／反义／形近），词形变化收进中心词外面的虚线气泡，每类关系各占一个扇区并标出数量（如 `Synonyms 10/12 +`）；每个词外圈还有进度环，表示"看过／在学／已掌握／薄弱"。左侧是词表与词详情。除了图，还有选择题／拼写／回忆三种测验、可点词查义的分级阅读、全屏「环境模式」（Web Audio 实时合成的四季音景）、学习护照、CSV 自定义词书与 AI 家教对话。

- **关键亮点 / 结论**：
  - **"词邻居"这个切入点是对的**：README 的原话是记 `abandon` 时旁边摆着 `desert`、`forsake`、`give up` 和 `abandonment`、`abandoned` 会更好记——每次复习一个词，等于顺手复习了它的一圈亲戚。
  - **图的数据是可复现的，不是拍脑袋**：32.6 万条链接全部给出数量与来源——屈折变化 125,612（ECDICT 词形码）、形近拼写 120,946（LCS 相似度 ≥ 0.75 且排除同族词）、近义词 87,971、近义辨析 74,008（"commonly confused" 注释）、派生词 6,221、反义词 **0（尚未采集，已列进路线图）**。愿意把"0"写出来的项目不多。
  - **记忆模型是显式的**：每次答题都会推进词的状态 `UNFAMILIAR → FAMILIAR → LEARNED → MASTERED` 并写入下次复习日期；路线图里还提到已内置 FSRS-6 实现但尚未接上排程。
  - **小模型微调的对照实验很有说服力**：WordLink-Edge 基于 Qwen2.5-1.5B-Instruct 做 SFT + DPO，任务是"给定 CEFR 等级与目标词表，输出一段含这些词的故事 JSON"。90 题基准上：微调前目标词命中 63.06%、合法 JSON 82.22%；SFT 后 88.06% / 100%；DPO 后 87.78% / 100%。同规模对照中，7B 零样本只有 39.72% 命中且**合法 JSON 为 0%**，而教师模型 DeepSeek-V3 是 97.78% / 100%。结论一句话：这类强格式约束任务上，**任务微调比堆参数更划算**。
  - **状态写得很诚实**：作者明确标注模型"已训练已评测，但 Web 应用还没跑它"，现在的 AI 功能走的是任意 OpenAI 兼容接口，浏览器端 WebGPU 推理还在路线图里。

- **适用场景 / 启发**：
  - 备考与词汇量爬坡（尤其雅思／托福这类需要辨析近义词的），词图比线性词表更贴需求；也可以导入自己的 CSV 词书。
  - 对做 AI 教育产品的人，这是一个完整样板：开放词典数据 → 关系挖掘脚本 → 图 UI → 记忆状态机 → 小模型写故事，每层都有对应目录与文档。
  - 上手注意三点：其一，自部署要 Node 20+ 与 Docker（PostgreSQL），且 `npm run migrate` 导入词典并加载 32.6 万条边**耗时明显**；其二，最快的体验方式是设 `DEMO_MODE=true` 跳过登录，AI 功能才需要配 LLM 网关；其三，代码 MIT，但 `data/` 里第三方词典资源（如 ECDICT）需逐个看各自条款，模型权重另遵 Qwen2.5 许可。

**为什么要看邻居**

> Most vocabulary apps drill words one at a time. But you remember *abandon* better when you also see
> *desert*, *forsake* and *give up* next to it, and *abandonment*, *abandoned* around it.

**图怎么编码信息**

> - **Colour = relation type.** Toggle synonyms, near-synonyms, antonyms and look-alikes from the toolbar.

> - **Your progress on the map.** A ring around each word shows how well you know it: a quarter once you have seen
>   it, two thirds while learning, closed when mastered, red when it is weak.

**记忆状态机**

> each quiz answer moves a word through UNFAMILIAR → FAMILIAR → LEARNED → MASTERED and sets its next review date (`src/lib/memory.ts`)

**微调带来的差距**

> Fine-tuning adds 25 points on the same 1.5B model, while a 7B model without fine-tuning fails the format entirely.

**模型的当前状态**

> **Status.** The model is trained and benchmarked, but the web app does not run it yet: its AI features call
> an OpenAI-compatible API. Running WordLink-Edge in the browser with WebGPU is on the roadmap.

**数据来源与许可**

> Code: [MIT](LICENSE). `data/` bundles lexical resources from other projects, including
> [ECDICT](https://github.com/skywind3000/ECDICT) (MIT); check each source's terms before reusing the data on its
> own. Model weights follow the [Qwen2.5 license](https://huggingface.co/Qwen/Qwen2.5-1.5B-Instruct).
