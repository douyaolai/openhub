# 英语语法笔记

## 一句话摘要
> INet 社区做的一份中文英语语法笔记：主张"把复杂语法掰碎了讲"，方法论取自尤雨溪——语法是用来理解句子的工具，不是用来背的，语感只能在使用中长出来。

## 核心分析与要点

- **核心内容**：一个面向程序员的语法学习项目，起因是社区里不少人英语薄弱，而英语直接影响技术信息的获取效率。内容全部以 Markdown 放在 `docs/` 目录，用 VuePress 生成站点、GitHub Actions 自动发布到 GitHub Pages，也可克隆到本地跑 `yarn docs:dev`。5.8k Star、MIT 许可，贡献可通过 issue 与 PR 参与。

- **关键亮点 / 结论**：
  - **立场明确反对"背语法"**：README 直接引用尤雨溪的观点——"你需要做到的是借助语法去理解你看不懂的句子，而不是去记忆语法本身"，语法过了初学者的坎就不必再刻意研究。
  - **强调主动使用**：引文里说"语感的培养绝对不能只靠被动的接收，必须要靠主动的使用"，只看书看剧提升有限，要写要说；具体手段是背新概念 + 背词汇。
  - **给出了下一步路径**：这份笔记只完成"语法练习"第一步，后续建议接百词斩与新概念英语作为教材。
  - **工程形态干净**：纯 Markdown + VuePress，内容可直接阅读、可 fork 续写，不依赖任何后端。

- **适用场景 / 启发**：
  - 适合想系统补一遍中文语法讲解的程序员，尤其是"能读文档但长句读不懂"的那类；也可作为技术团队内部学习材料。
  - 作为开源文档项目的样板：内容与站点分离、CI 自动部署、贡献流程清楚。
  - 需要注意：仓库最近一次推送是 **2023-12-20**，内容更新已停滞两年多；笔记本身是二手整理，深度不及专著，遇到争议语法点仍应查证原始资料。

**项目缘起**

> 这个项目由 [xiaoxunyao](https://github.com/xiaoxunyao) 提出，并且大量文本编辑的工作由他负责查阅资料和整理资料完成。在这个社会学会英语对于每位程序员的帮助都是有重大意义的，所以 [INet](https://github.com/hzpt-inet-club) 社区开始着手编写语法笔记，争取将复杂困难的语法知识点掰碎了告诉大家。

**为什么值得学（引尤雨溪）**

> 不仅英语差会成为瓶颈，英语好还能成为优势，因为学习效率会比别人高。像我这样半路出家自学的人，只能靠英语了...        --尤雨溪

**语法该怎么用**

> 语法也不是完全不需要。或者说，你需要做到的是借助语法去理解你看不懂的句子，而不是去记忆语法本身。理解的过程就是培养语感的过程。

**语感只能在使用中长出来**

> 但是联系到题主的问题，语感的培养绝对不能只靠被动的接收，必须要靠主动的使用。只看书看剧带来的提高是非常有限的，语感只有在使用中才能提高。所以，除了看和听，还要写和说。

**没有捷径**

> 所以说到底还是没有什么捷径可走的，想提高英语总得有所付出。 --尤雨溪
