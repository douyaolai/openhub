# StoryCraft

## 一句话摘要
> 面向 3–5 岁的 AI 儿童绘本生成器：给一个创意就出完整故事与逐页插图，支持中英双语、8 种画风、导出 Kindle 友好的 PDF。

## 核心分析与要点

- **核心内容**：输入一个创意点，AI 生成完整故事并为每页配图；支持中英双语（可作语言学习材料）、8 种画风（漫画、动画风、国风、水彩等），可编辑故事、重新生成单页图，最终导出为适配 Kindle 与平板的 PDF。部署是 Python + API Key + 环境变量，几分钟可跑起来。
- **关键亮点 / 结论**：
  - **定位很具体**：3–5 岁，意味着句子短、图占主导——这比"通用绘本生成"更可落地。
  - **PDF 输出对准电子阅读器**，不是只给屏幕看，说明作者考虑了真实使用场景（睡前共读）。
  - README 第一句写着"这是云爸送给女儿云的礼物"，项目动机清晰，产品感来自真实需求。
- **适用场景 / 启发**：家长做专属绘本、老师做教学材料。与知识库里 2026-11-25 记录的《AI 儿童绘本小程序》构思可直接对照：StoryCraft 已验证"生成 + 双语 + 导出"这一段，**尚未覆盖印刷与订阅**，恰好是那个构思里最难的两块。68 Star，MIT。
