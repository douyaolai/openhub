# 儿童英语学习伙伴

## 一句话摘要
> 一个离线优先的儿童英语 PWA：90 篇分级课程、1,074 条离线词典、25 MB 预生成音频，配上闯关、Buddy 进化与词卡复习——数据全在本机，多孩共用一个设备也能各自记进度。

## 核心分析与要点

- **核心内容**：Magic English Buddy 是一个可安装到主屏幕的英语学习应用，课程、词典与学习记录都存在本机（IndexedDB），不需要账号和云端。学习路径是七级地图（L1 萌芽之森 20 课 → L7 创世之核 8 课，共 90 篇），每课含朗读跟读与四类练习（听音辨图、单词拼装、句子排序、魔法填空），60 分通过并解锁下一关。

- **关键亮点 / 结论**：
  - **离线做得彻底**：不仅应用资源用 Service Worker 缓存，1,721 个 Kokoro 预生成 MP3（约 25.3 MB）也做成按需下载包，支持断点续传、SHA-256 校验、多包共享片段去重；词典 1,074 个词条覆盖课文中 4,253 次可点击词——这是"离线可用"而不是"离线打不开"。
  - **多孩子共用设备的处理方式很实在**：用本机"学习档案"隔离地图、答题历史、词卡与成就，切换档案即切换学习者；明确不提供账号密码或云端身份，也不做跨设备同步。
  - **游戏化不是装饰**：Buddy 四阶段进化（魔力 100/500/1,500 触发）、词卡、成就、连续学习记录、可导出 PNG 的学习证书，构成了完整的正反馈闭环。
  - **朗读对齐是技术难点，它写清了**：播放器读取 Kokoro 音频的实际词级时间点来驱动逐词高亮，取不到预生成音频时才退到系统语音，并提示"可靠的离线朗读应提前下载音频包"。
  - **边界写得很坦白**：没有云端同步与扫码导入、跟读只有示范与录音回放而无发音评分、词典与音频未经人工教学审核、实体 iPhone 的麦克风/耳机/锁屏回归仍待补。这种"自己先说不足"的 README 在儿童教育类项目里不多见。
  - **工程与测试配套完整**：React 19 + TypeScript + Vite 6 + Zustand + Dexie，Vitest/Testing Library 单测、Playwright 端到端（Chrome + WebKit），另有 `pnpm audit:content` 专门检查课程、词形与词典覆盖。

- **适用场景 / 启发**：
  - 给 6–10 岁孩子做英语启蒙的家长可以直接用在线版（GitHub Pages 部署），装到 iPad 主屏幕后断网也能学。
  - 对开发者是一个"纯前端离线教育应用"的完整样本：PWA 缓存策略、音频按需下载与校验、IndexedDB 多档案数据模型、可导出备份格式（v2 兼容 v1），都可以拆开参考。
  - 使用时注意两点：其一，**恢复备份会替换本机全部学习记录**，恢复前应先导出；其二，许可方面仓库使用自带 LICENSE（GitHub 识别为 NOASSERTION），词典数据来自 ECDICT 另有单独许可，商用或二次分发前需分别确认。

**定位**

> 离线优先的儿童英语学习伙伴，让阅读、跟读、闯关和复习成为一次魔法冒险。

**数据存在哪里**

> 课程、词典和学习记录保存在本机，支持多个孩子共用设备，通过独立学习档案保留各自的进度。

**通关规则**

> 课程练习达到 **60 分**即通过，并解锁后续关卡；已通过课程可再次练习。

**音频与高亮的关系**

> 朗读优先使用 Kokoro 预生成音频，播放器读取实际词时间点来驱动高亮；无法使用预生成音频时尝试系统语音。系统语音的可用性取决于浏览器与设备，可靠的离线朗读应提前下载音频包。

**备份的风险**

> 恢复前会展示备份摘要并要求确认。**恢复会替换本机全部学习记录**，需要保留当前记录时请先导出备份。已下载音频会保留；音频文件和临时跟读录音不随备份迁移。

**自己承认的边界**

> 本机档案用于区分学习进度，不提供账号密码或云端身份。自动跨设备同步、扫码导入和班级汇总尚未实现。

> 词典覆盖率与音频技术校验不代表完成教学审核，全量释义、例句和音频仍需人工教学审核。

**项目取向**

> Made with ❤️ for educational equity
