# TT说卡

## 一句话摘要
> 一个中文跨境金融导航站：把香港银行开户、港美股券商开户、跨境汇款与境外手机卡四条线做成结构化教程，并附券商邀请码与福利对比表——本质是**内容导流 + 邀请返利 + 付费咨询**的组合。

## 核心分析与要点

- **核心内容**：站点按四条主线组织：海外银行开户（港澳银行教程、内地见证开户、虚拟银行对比）、港美股券商（开户流程、入金出金、邀请码与福利）、跨境汇款（FPS / eDDA / 电汇的区分与操作）、境外手机卡（选卡、实名、保号）。每类都给出一条「N 步阅读路线」，从"核对资格"到"实操开户"逐级展开，适合完全没接触过跨境开户的人按序读。

- **关键亮点 / 结论**：
  - **工具页比教程更有独立价值**：汇率查询、香港银行定存利率榜、港卡 ATM 提款收费对比、QDII 额度查询、美股财报日历、美股税费计算器（股息预扣税 / 境内补税 / 税后收益）、富途账单税务核算——这些是可直接用的查询与计算工具，不依赖它的教程。
  - **券商对比表是流量核心**：列了十余家（复星、腾达 GigaMoney、老虎、盈立、Webull、卓锐、艾德、云锋有鱼、都会 Doo、致富、必贝、熊猫等），每行含邀请码、福利门槛、最低入金、是否需海外身份。表格信息密度高，但**福利数值随活动变化，且作者能从中获得返利**，必须以券商当期页面为准。
  - **内容有明确的时效标注**：博客部分按日期更新（页面显示到 2026-11-19），涉及汇丰"最红自主奖赏"登记、恒生 App 预填开户、盈立新加坡入金路线等具体活动，属于"会过期的实操信息"。
  - **FAQ 覆盖了真实门槛**：地址证明怎么办、内地居民能否开港券商户、没有海外地址证明如何变通、虚拟银行是否可全程线上——这几条是新手最常卡住的地方。
  - **商业属性要看清**：页面自述"已协助 50000+ 卡友完成开户，累计薅福利 2 万+ 港币等值"，并引导「1v1 付费咨询」。这些数字是**站点自称，无第三方验证**；邀请码换来的福利与作者的返利是同一套机制的两端。

- **适用场景 / 启发**：
  - 把它当**索引与对比工具**用：查某家银行/券商的开户前置条件、某条汇款通道怎么走、某个费率怎么算，比当"教程"逐字读更有效率。
  - 作为"知识库 + 返利"商业模式的样本：结构化内容 → 搜索流量 → 邀请码转化 → 付费咨询，四层变现路径清晰。
  - 使用前须知三点：其一，所有"最高 XX 港币"均为活动期口径，且往往附加入金与留存条件；其二，跨境开户涉及外汇管理与当地法规，合规责任在个人；其三，本站明确声明"未经许可严禁转载"，因此这里只做摘录与评述，不整篇搬运。
