# VIDA文章档案

## 一句话摘要
> 一位自称「00后富一代」的知乎创作者的全量内容归档站：564 篇想法／回答／专栏、82 张配图，从 2020 年写到 2025 年，主线是「用轻资产套利思维赚钱」——覆盖加密市场、美股／A股、创业与个人 IP 运营。

## 核心分析与要点

- **核心内容**：这是一个纯静态、单页式的个人文章档案站。首页以列表形式呈现全部 564 篇内容，支持关键词搜索与「按时间／按热度」排序，点开进入单篇阅读页。数据据页面内嵌 JSON 统计：共 564 篇、82 张配图，正文合计约 13.3 万字，时间跨度 2020-11-23 至 2025-02-27；体裁为想法 448 篇、回答 88 篇、专栏 28 篇；累计赞同约 8.04 万，单篇赞同中位数 51、均值约 143、最高 2541。内容全部指向知乎（`zhihu.com` / `zhuanlan.zhihu.com`）原始链接。

- **关键亮点 / 结论**：
  - **内容重心在金融投机而非泛商业**。按关键词覆盖统计（一篇可命中多类）：投资／美股／A股 233 篇、加密／Web3 216 篇、创业／生意 133 篇、社会时政 120 篇、套利／投机 96 篇、成长／人生建议 89 篇、AI／技术 47 篇、生活／旅行 39 篇。因此归入「Web3与金融」而非「产品与商业」。
  - **作者有一套自洽的方法论并在反复复述**：轻资产套利 + 信息差 + 高赔率小仓位试错（「尝试 10 个机会当中能中一个成功的就能起飞」），加密与美股是主要战场，个人 IP 是放大器。
  - **高赞集中在「给年轻人的方法论」而非纯行情贴**：Top 5 为《关于创业有什么建议？》(2541)、《给00后们的话》(2371)、《如何看待2022年金融危机？》(2216)、《普通人怎样才能一步步走向成功？》(1954)、《我爸的A股投资思维》(1950)。行情类内容（如 2025 年的美股布局、Bybit 被盗评论）热度明显低于价值观类长文。
  - **技术实现极简**：单个 HTML 文件（约 9.7 MB）内联 React 打包产物与全部正文数据，配图以 base64 内嵌，无外部 JS/CSS 请求，路由用 URL hash（`#/article/<id>`），可离线保存后直接打开。代价是普通抓取工具只能拿到空壳 DOM，必须解析内嵌的 `JSON.parse('…')` 才能取到正文。

- **适用场景 / 启发**：
  - 作为「个人 IP 全量语料」的样本：研究一个财经类创作者 5 年间的话题漂移（2021 年 303 篇为高峰，2022 年骤降至 65 篇，2023 年后稳定在每年 70–90 篇）。
  - 作为静态档案站的做法参考：把 500+ 篇内容压进单文件、零后端、零 CDN 依赖，适合长期存证与防删帖。
  - 阅读时需注意：全文为作者个人观点与自述，含明确的收益宣称（如「现金流 1 亿+」「美股头寸约 1000 万美元」），站点未提供任何第三方凭证，**不构成投资建议**。
