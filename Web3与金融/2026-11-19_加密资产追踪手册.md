# 加密资产追踪手册

## 一句话摘要
> 慢雾（SlowMist）开源的中文链上追踪入门手册：从公链模型、浏览器与 MistTrack 工具，到七种资金流动套路、被盗后的处置顺序与四个真实案例——核心观点是"链上看得见"不等于"追得回"。

## 核心分析与要点

- **核心内容**：一本结构完整的中文手册，面向普通投资者、项目方、媒体、法律援助与执法人员。共十章：基础概念（主流公链差异、UTXO 与账户模型、浏览器）→ 追踪工具（MistTrack 与社区工具）→ 常见资金流动模式 → 被盗怎么办 → 跨链桥追踪 → 隐私工具（Mixer）追踪 → NFT 追踪 → 地址行为分析 → 四个案例 → 资产冻结与追回建议。仓库创建于 2025-08-14，最近推送 2025-12-05，更新日志显示 2025-12 补充了 MistTrack 介绍、Bridge 分析与案例章节。

- **关键亮点 / 结论**：
  - **先立观念再讲工具**：开篇就点明"链上的'可视化'只是第一步，真正的'可追回'需要克服一系列复杂的挑战"，并用数据说明规模——2024 年至 2025 年上半年，SlowMist Hacked 统计的 531 起安全事件造成 43.86 亿美元损失；ScamSniffer 统计的 Wallet Drainer 钓鱼造成约 5.34 亿美元损失、37.56 万个受害地址。
  - **七种资金流动模式是最有复用价值的一节**：剥离链（Peel Chain）、一对多分发（扇形拆分）、多跳转移、混币器、跨链桥跳转、多对一归集、P2P/OTC 脱链。每种都给了行为特征而非只给名词，例如"每个地址仅使用一次并迅速转出""统一注入额度、特定等待时间、同步提现"。
  - **被盗后的顺序讲得很硬**：第一优先级是止损（分紧急止损与避免二次伤害两阶段，含检查恶意多签、用 revoke.cash 取消授权、防"假客服"二次诈骗）；紧接着是"保护现场"——**不要马上关机、重装、删插件**，因为那会破坏取证环境。这条反直觉但关键。
  - **没有回避难点**：单列"可申请冻结的 Token"一节，也明确多数交易所不会因个人投诉就冻结地址，冻结与追回高度依赖发行方、平台与司法配合。
  - **利益透明度**：工具章节重点介绍 MistTrack，而 MistTrack 正是慢雾自有产品——这不影响手册价值，但阅读时应知道工具推荐与出品方的关系。

- **适用场景 / 启发**：
  - 被盗后的**应急手册**：按"止损 → 保护现场 → 初步分析 → 联系机构 → 报案 → 持续跟进"的顺序执行，比临时上网搜帖子可靠。
  - 项目方与交易所风控、律所与媒体取证入门的共同读物：七种模式可以直接作为"异常资金流"的检查清单。
  - 需要注意：仓库**未声明开源许可证**（GitHub 元数据为空），转载或商用前应联系作者；手册定位是入门科普，不构成法律意见，实际追回仍取决于司法辖区与平台配合。

**看得见 ≠ 追得回**

> 链上的“可视化”只是第一步，真正的“可追回”需要克服一系列复杂的挑战。

**匿名性的两面**

> 匿名性是加密货币的一把双刃剑。它赋予用户隐私保护权的同时，也让一些恶意行为更难被精准识别。

**剥离链的定义**

> 剥离链（Peel Chain）是指一种通过一系列冗长的小额交易来清洗大量加密货币的技术，是区块链分析中常见的一种交易模式。

**多跳转移的行为特征**

> 攻击者常通过快速、多跳的方式转移资金，每个地址仅使用一次并迅速转出，且大多不参与任何链上 dApp 交互。

**模式会组合，关键是看意图**

> 虽然以上模式常见，但值得注意的是，攻击者本身也在不断更新手法。资金路径可能混合多种策略，例如“拆分 \+ 跨链 \+ 混币 \+ 再归集”，而这种非线性组合才是大多数真实案例中所呈现的复杂场景。
