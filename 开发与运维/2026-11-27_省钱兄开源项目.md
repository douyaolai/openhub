# 省钱兄开源项目

## 一句话摘要
> 西安省钱兄网络科技有限公司的开源项目展示站：6 个自研项目（同城外卖、拓客助手、模板商城、企微 SCRM、运维监控面板、UniApp 工程模板）开放源码，主打「可二开、可商用交付」。

## 核心分析与要点

- **核心内容**：站点首页列出六个自研项目，每项给出定位与能力边界，另设「需求板」接受定制需求（可按项目提交，也可发布需求供他人对接）。站点是纯前端单页应用，文案与项目数据打包在 JS 里，服务端只返回空壳 HTML。

  | 项目 | 定位 | 能力范围（页面自述） |
  |---|---|---|
  | 同城外卖开源版 | 完整外卖业务闭环，Java 多端 | 用户点餐、商家接单、骑手配送、后台运营；源码无加密、不限制域名；提供部署文档 |
  | 拓客助手开源版 | AI 内容生产与发布辅助 | 关键词库、文章池、发布策略、日志追踪；按平台规则生成文案素材 |
  | 模板商城开源版 | 源码售卖站的前台参考实现 | 商品展示、订单与下载交付流程；可按业务裁剪支付与交付模块 |
  | 企业微信 SCRM 开源组件 | 企微 SCRM 基础能力示例 | 会话存档、客户标签、外呼触达、客户画像与触达记录 |
  | 运维监控面板开源版 | 轻量运维监控与知识沉淀 | 服务器巡检、异常告警、知识库、异常工单记录 |
  | 小程序 / App 统一工程模板 | UniApp 工程模板 | 登录、列表、详情与请求封装示例，统一多端开发规范 |

- **关键亮点 / 结论**：
  - **卖点不是"开源"本身，而是"能直接二开上线"**：页面反复强调源码无加密、不限域名、带部署文档、可按业务裁剪——这是面向外包与创业团队交付的语言，不是面向社区贡献者的语言。
  - **项目选型集中在小生意的高频需求**：外卖、获客、商城、SCRM、运维面板，全是中小团队"要么买要么自己写"的东西，用开源版做起点能省掉大量骨架工作。
  - **需求板是配套商业动作**：项目列表 + 定制需求对接，形成"先用源码获客、再谈定制"的漏斗。
  - **一处需要留意的实现**：页面头部内嵌了一段自建埋点脚本，加载即向 `sqxai.xiansqx.cn` 上报 `page_view`，并有心跳与离场上报——访问该站会被记录（无 cookie 追踪，用 localStorage 生成 visitorKey）。

- **适用场景 / 启发**：
  - 想快速起同城配送、源码商城或企微工具的项目，可以拿它的开源版当地基；也能作为"开源版引流 + 定制交付变现"这种商业模式的观察样本。
  - **使用前需自行核实三件事**（站点未提供）：① 各项目仓库地址与许可证——页面只说"开放源码地址"，未在首页给出链接与 License；② "无加密、不限域名"是营销承诺，实际以仓库 LICENSE 为准，商用前必须确认授权范围；③ 项目完成度与维护活跃度未知，页面部分条目写着"敬请期待开源"。
  - 页面上出现的客服联系方式（微信号、手机号）形如占位示例数据，不宜当作真实联系方式使用。
