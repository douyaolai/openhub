# crawl4ai

## 一句话摘要
> 给 AI agent 用的开源爬虫：把网页转成干净 Markdown 喂 RAG，或直接抽成结构化 JSON，附托管云与自托管两种用法。

## 核心分析与要点

- **核心内容**：仓库本身是 Apache-2.0 的爬虫引擎（Python），同时也是 Crawl4AI Cloud 的开源底座。三种典型产出：给 RAG 用的干净 Markdown、按 schema 抽取的结构化 JSON、以及实时网页搜索。云端提供托管 API（每月 1,000 免费额度、无需信用卡），但爬虫可以自己用 Python 或 Docker 跑。
- **关键亮点 / 结论**：
  - **"开源内核 + 托管服务"** 的组合：想要省事就用 `api.crawl4ai.com`，想控数据就自托管，两条路共用一套能力。
  - 面向 agent 做了适配：可直接接 Claude Code、Cursor、Codex，并提供 MCP 支持。
  - 87.8k Star、9,159 Fork，是这个品类里体量最大的项目之一，社区与文档成熟度高。
- **适用场景 / 启发**：给 RAG 补数据、做竞品抓取、把网页变成 agent 可读的上下文。注意 Apache-2.0 附带署名要求（README 有 Attribution Requirements 一节），商用前要看清楚。
