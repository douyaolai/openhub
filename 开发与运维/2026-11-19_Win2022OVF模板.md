# Win2022OVF模板

## 一句话摘要
> 第三方整理的 Windows Server 2022 Datacenter ×64 OVF 模板发布页：预配好远程桌面、常用工具与一批策略项，导入 VMware 后自动 sysprep——省掉装系统调环境的半天，但镜像来源与授权需要自行把关。

## 核心分析与要点

- **核心内容**：sysin 发布的虚拟化模板，适用于 VMware ESXi / Workstation / Fusion，系统为 Windows Server 2022 Datacenter（带桌面体验）。文章给出最近三个版本的分档：2026-06（Build 20348.5256）、2026-08（Build 20348.5499）、2026-10（Build 20348.5761），每个约 6 GB，默认提供简体中文版，需要英文版需注明。

- **关键亮点 / 结论**：
  - **开箱即用的程度比较高**：默认启用远程桌面与 ICMPv4 防火墙规则、完成远程桌面性能优化（禁登录背景、禁锁屏、灰底桌面）、关闭遥测、把 Windows Update 改为手动、Administrator 密码设为永不过期，并加了 Command Prompt / PowerShell / FileHash 的右键菜单。
  - **预装了一批免费工具**：7-Zip、AutoRuns、IObit Unlocker、Firefox（用策略禁用自动更新）、以及 Defender Control 与 Windows Update Blocker 两个"关闭开关"；组件层面加了 .NET Framework 3.5、Telnet Client、SNMP Service、Windows Backup。
  - **兼容性写得明确**：默认 VM 硬件版本 11，兼容 ESXi 6.0、Fusion 7、Workstation 11 及以上，VM-Tools 13.1.5；部署端推荐 Fusion 13+ / Workstation 17+ / vSphere 7.0U3+。
  - **两个容易被坑的部署细节**：第一，vSphere Client 严格校验 OVF 属性，Password 字段必填且要满足系统密码复杂性（≥6 位、四类字符取三类）；第二，子网掩码要用 CIDR 表示（255.255.255.0 填 24），主机名限 1–15 字符且不能全数字。
  - **语言版本的坑有解释**：2023 年 6 月起分成英文版与简体中文版两个独立版本，原因是官方系统文件每月更新而语言包长期不同步，切换语言后会导致系统或自带应用报错或功能异常。

- **适用场景 / 启发**：
  - 需要快速起一台 Windows Server 做测试、兼容性验证或开发调试的，可以省掉装系统与调策略的时间。
  - 但**三点风险必须自己评估**：其一，这是第三方修改过的系统镜像，属于供应链信任问题，导入前应核对页面给出的 SHA256 并只用于隔离环境；其二，下载并非免费，页面上明确要通过捐赠获取专享链接，且作者声明"仅供个人学习和研究使用"；其三，Windows Server 本身的授权仍需自行解决，镜像来源不等于授权。
  - 页面里那些注册表与策略改动（关闭遥测、禁用更新、密码永不过期）在测试环境很省事，但在生产环境往往与安全基线冲突，值得注意。
