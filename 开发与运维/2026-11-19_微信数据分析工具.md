# 微信数据分析工具

## 一句话摘要
> 微信 4.x 数据库解密与分析：聊天记录、朋友圈、联系人、收藏、转账红包等 10 类内容可导出，附带年度总结。

## 核心分析与要点

- **核心内容**：面向个人微信数据的解密与导出工具，覆盖聊天记录、朋友圈、联系人、收藏、好友验证、小程序、视频号直播、转账与红包、服务号记录、账号数据归档共十类内容。
- **关键亮点 / 结论**：
  - 导出格式齐全：HTML / JSON / TXT / Excel，聊天记录与朋友圈还能连同资源打包成 ZIP。
  - 支持按会话、消息类型、时间、关键词做筛选，适合"只想导出某段关系"的场景。
  - 提供 Windows 与 macOS 桌面安装包，也支持源码运行与自行打包 EXE/DMG。
- **适用场景 / 启发**：个人年度回顾、重要对话留档。需注意仓库**未声明开源许可证**，二次分发与商用前应先联系作者；同级工具还有 SIWX、Moect，可按导出格式与是否需要 MCP 来选择。
