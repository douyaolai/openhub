# Moect

## 一句话摘要
> Windows 微信 4.x 聊天记录导出与离线归档：好友/群聊、朋友圈、表情与文件一并留存，导出 HTML 可离线搜索。

## 核心分析与要点

- **核心内容**：在 Windows 上读取并导出微信 4.x 的聊天记录，支持好友/群聊、头像、图片、GIF 表情、音视频、文件、链接、小程序、引用回复与合并转发。
- **关键亮点 / 结论**：
  - 导出格式多：HTML / JSON / JSONL / TXT / CSV / Markdown，其中 HTML 可离线阅读、搜索、按时间筛选，还能展开合并转发。
  - 体验做得比同类细：八种主题色、深浅色、鸿蒙字体、批量任务、消息搜索与时间筛选、一键安装包。
  - 1.3.0 补上了收藏导出（测试）与群系统消息读取。
- **适用场景 / 启发**：偏"归档与阅读"而非"数据分析"，适合把多年聊天记录变成可翻阅的个人档案。注意作者因备考暂停更新至 12 月 23 日，期间只处理重大问题；许可证 GPL-3.0。
