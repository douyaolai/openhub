# codeg

## 一句话摘要
> 多 agent 编程工作台：把 Claude Code、Codex、OpenCode、Grok Build 等二十个 agent 聚到一个界面，还能互相委派。

## 核心分析与要点

- **核心内容**：把所有 AI 编码 agent 的会话收进同一个界面，用统一的结构化对话（工具卡片、实时 diff、可交互回复）呈现，而不是各自一个终端窗口。
- **关键亮点 / 结论**：
  - 会话可搬迁：能导入、搜索、恢复各 agent 落盘的历史，再交给另一个 agent 接着做——这解决了"换 agent 等于从零开始"的问题。
  - 协作有具体机制：用 `@` 跨 agent 委派，或把待办排队，让它们在各自的 git worktree 里无人值守地跑。
  - 部署形态全：桌面应用、自托管服务、Docker，以及 iPhone/iPad/Android 与 Telegram、飞书、微信。
  - 内置二十个 agent，并且任何符合 ACP 协议的 agent 都能接入。
- **适用场景 / 启发**：同时使用多个 coding agent 的团队/个人，尤其是需要并行跑多个任务并统一查看 diff 的场景。
