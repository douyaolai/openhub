# SIWX

## 一句话摘要
> 微信 4.x 聊天记录与朋友圈的本地归档工具：解密、浏览、搜索、8 种格式导出，纯 Python 不依赖外部二进制。

## 核心分析与要点

- **核心内容**：在 Web 控制台里跑完「发现账号 → 提取密钥 → 解密数据库 → 浏览聊天 → 恢复媒体 → 转码语音 → 导出」全流程，聊天记录与朋友圈（`sns.db`）双线归档。
- **关键亮点 / 结论**：
  - 零外部依赖做得很彻底：微信语音 SILK 用纯 Python 的 `pilk` 解成 WAV，朋友圈图片视频用纯 Python 的 ISAAC64 流解密，不需要 ffmpeg。
  - 工程细节扎实：SQLCipher 逐页 4KB 流式解密、K 路归并导出、按 `mtime + size + key` 的两级缓存，万级消息不会把内存吃爆。
  - 内置 MCP Server（stdio + JSON-RPC 2.0，11 个工具），聊天记录可以直接被 AI 客户端检索——这一点比同类工具进一步。
  - 全程只监听 `127.0.0.1`，不上传数据。
- **适用场景 / 启发**：个人聊天记录备份与"交给 AI 检索自己的历史"。注意 README 明确仅限处理本人有合法访问权限的数据，且禁止商用。

> **把微信 4.x 的本地聊天记录与朋友圈，变成可浏览、可搜索、可导出、可交给 AI 的个人资料库。**

> 密钥提取采用 **propose-verify 分离**的策略链（密钥库 → MMKV → WCDB Config.Cipher → 内存扫描），策略只产出候选，由编排器统一做 HMAC 校验后入库；密钥落盘时经 Windows DPAPI 加密，不存明文。

> - 密钥已缓存时通常可直接复用，速度很快。 - 密钥未缓存时，点击"提取并解密"后请在 **60 秒内重新登录微信**——密钥只在登录期间可抓。
