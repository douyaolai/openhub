# 自动字幕skill

## 一句话摘要
> 本地跑的视频自动字幕技能：转写、校对、烧字幕、出 SRT/VTT、多语言翻译，还能按批准后发布。

## 核心分析与要点

- **核心内容**：一个免费开源的自动字幕技能，覆盖从转写到发布的完整链路：转写（带逐词时间戳）→ 校对专有名词与数字 → 按各平台形态烧入创作者风格字幕 → 生成 SRT/VTT 字幕文件 → 翻译成其他语言 → 在你确认后发布或排期。
- **关键亮点 / 结论**：
  - **转写默认在本地跑**（faster-whisper，Apple Silicon 上可用 mlx-whisper），长视频可选自备 Groq 或 Deepgram 的 key，或直接复用视频已有字幕——不强制付费 API。
  - **烧字幕前逐行校对**：用你的专有名词表核对，避免把人名、数字写错。
  - 提供 8 种字幕样式（高亮当前词、大粗体、彩色药丸、逐词显示、双行、清爽字幕、极简、单词逐个出现），并支持 9:16 竖屏等常见比例。
- **适用场景 / 启发**：批量处理口播、访谈、课程视频的字幕与多语言版本。项目很新（12 Star），发布环节依赖 WoopSocial，实际效果建议先用自己的一条视频验证。
