# 经营合规边界清单

## 一句话摘要
> 11 组「这么做违法、换个做法就合规」的对照：核心思路是**同一需求换个形式或补上资质**——彩票与有奖销售、博彩中介与持牌经营、放贷与技术服务、培训与沙龙，边界都在形式与许可上。

## 核心分析与要点

- **核心内容**：全文是 11 条对照，句式统一为「A 违法，但 B 合规」，按场景可归成五组：

  | 场景 | 对照（左为文中的违法项，右为合规项） |
  |---|---|
  | 博彩与抽奖 | 私自发行两元彩票 ✗ / 2.1 元瓶装水做瓶盖中奖促销 ✓；国内做博彩中介 ✗ / 澳门持证经营 ✓（不得到内地拉人） |
  | 有奖销售 | 赌博 ✗ / 合规盲盒与有奖销售 ✓（奖金上限 5 万）；纯竞技比赛奖金无上限 |
  | 金融与借贷 | 非法吸存（要判刑） / 预付卡合规但**不得付息、不得保本**；无金融资质放贷 ✗ / 只做技术服务与技术对接 ✓；内地个人开银行或保险公司 ✗ / 香港申领牌照且不入境揽客 ✓ |
  | 资质与审批 | 收费培训需资质 / 纯分享纯交流的沙龙不需要；内容发行需审批备案 / 平台付费短视频与付费直播可行；异地经营性办事处需营业执照 / 只做信息对接的联络处不需要 |
  | 特许与刑民边界 | 内地私产私售香烟（重罪）/ 境外合规生产 + 国内审批进口销售 ✓；抢银行（刑事重罪）/ 银行贷款经营亏损（民事债务纠纷）；公立 110 急救中心不能私人开办 / 宠物医院的宠物 110 急救可以 |

- **关键亮点 / 结论**：
  - **共同逻辑只有一个**：决定合法与否的不是"这门生意"，而是**形式、资质、地域**三件事的组合。同一种需求，换个载体（瓶盖、盲盒、技术合同、沙龙）或换到另一个辖区，结论可能完全反转。
  - **几条边界写得很窄**：预付卡"绝对不能给利息、不能保本"，一说就是违法吸存；境外牌照"只要不进入内地揽客"；这几句其实是在划线，而不是在给方法。
  - **奖金上限那句是唯一带具体数字的**：有奖销售奖金上限不超过 5 万，而纯竞技比赛奖金无上限——这是把"促销抽奖"与"竞技赛事"分开的典型例子。
  - **文本形态本身就是线索**：中间夹着"发言人"字样、编号从「一、」「2、」到「5、」不统一，说明这是从聊天或会议记录里摘出来的速记，不是成文的法律意见。

- **适用场景 / 启发**：
  - 当**提问清单**用很有价值：每一条都能转化为"我这门生意的形式、资质、地域分别是什么"的自查项，逼人把模糊的"应该没事吧"变成具体问题。
  - **但不能当答案用（我的判断）**：这 11 条全部省略了前提条件——资质要求、地方差异、审批层级、是否触及刑事红线——而文中涉及博彩、金融、烟草、培训、彩票的多条都属于强监管领域，类比一旦不成立，后果不是罚款而是刑责。文中反复出现的"绝对不能"也说明作者清楚边界之窄。
  - 建议做法：把这份清单当作"要去查哪几部法、问哪位律师"的索引，具体条文与地方执行口径仍须以官方规定与专业意见为准。
