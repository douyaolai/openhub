# 社媒技能合集

## 一句话摘要
> 给 AI agent 的 106 个社媒技能包：从策略、选题、写作到视频、设计、增长与复盘，覆盖整条内容流水线。

## 核心分析与要点

- **核心内容**：一套面向社交媒体运营的 agent 技能库，分策略与规划、写作（不同文体）、内容角度、平台打法、视觉与设计、视频、增长、社群与数据分析等模块，共 106 个技能，兼容 Claude、Cursor、OpenClaw、Hermes 等 40+ 种 agent。
- **关键亮点 / 结论**：
  - **先读品牌档案与语气指南再动笔**：作者强调每个技能写作前都会读你的 brand profile，避免"通用 AI 味"与编造数据。
  - **按当年平台规则写，而不是按 2023 年的经验**：每个技能编码的是当前算法、格式与平台机制，并明确经过事实核查与更新。
  - **发布环节需要你明确同意**：内容准备好后不会自动发，等你点头才发。
- **适用场景 / 启发**：一个人当一支内容团队用时，能显著压低"从选题到成稿"的时间。注意它是流程与写作规范的专业知识封装，产出质量仍取决于输入的品牌资料是否具体；MIT 许可，417 Star。
