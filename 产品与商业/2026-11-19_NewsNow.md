# NewsNow

## 一句话摘要
> 实时热榜阅读器：清爽 UI、GitHub OAuth 登录同步、抓取间隔自适应（最低 2 分钟），还带 MCP server。

## 核心分析与要点

- **核心内容**：一个聚合多平台实时热点的阅读前端，强调排版与阅读体验；登录后可同步收藏，并手动强制刷新缓存（默认缓存 30 分钟）。
- **关键亮点 / 结论**：
  - 抓取间隔按各源更新频率自适应（最低 2 分钟），用于降低被封 IP 的风险——这是多数聚合器会踩的坑，它写进了设计。
  - 支持 MCP：`newsnow-mcp-server` 可让 agent 直接读热榜，等于给 AI 开了一个"今天有什么新闻"的工具。
  - 部署路径清晰：Fork 到 Cloudflare Pages / Vercel 即可，无需登录与缓存时更简单；也支持 Docker 与数据库。
- **适用场景 / 启发**：自建个人资讯站；或作为「给 agent 接数据源」的现成 MCP 服务。TrendRadar 这类下游项目正是建在它的 API 上。
