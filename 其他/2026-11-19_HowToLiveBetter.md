# HowToLiveBetter

## 一句话摘要
> 高性价比人生指南：772 条建议，每条写明成本、收益、证据等级与原始出处，只引期刊论文和官方文件。

## 核心分析与要点

- **核心内容**：一本持续更新的中文生活指南，覆盖长寿防病、急救、省钱理财、法律红线、失业与工伤、医保社保、恋爱婚育、怀孕育儿、创业与平台合规、出国与技能。制度类内容按中国大陆现行规定写。
- **关键亮点 / 结论**：
  - 每条建议都标注「花掉什么、换回什么、证据有多硬」，来源限定为期刊论文与官方文件，少数引署名原创新闻并附网页存档——这种写法在中文科普里很少见。
  - 做了证据分级与性价比档，还配术语表解释数字的含义，降低了"看不懂统计"的门槛。
  - 交付形态多：网页检索、EPUB、PDF、离线单文件 HTML、Anki 牌组，另有供 Claude Code / Codex 使用的 skill，可直接"照书回答"并注明第几节第几条。
  - 作者自己说明这是备选单不是任务清单，且承认内容可能过时、各地政策执行不一。
- **适用场景 / 启发**：把生活决策（体检、报销、维权、生育）从"听人说"变成"看证据"。使用时仍需以当地部门、医生与律师的说法为准。
