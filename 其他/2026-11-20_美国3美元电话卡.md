# 美国3美元电话卡

## 一句话摘要
> 一份 20 页的实操长文（打印自 X 文章）：把 Ultra Mobile PayGo 这张 $3/月美国原生实体卡从选卡、避坑、激活、充值、Wi-Fi Calling 到封号与急救的完整路径讲透——核心结论是**不开 Wi-Fi Calling，这张卡等于随时会爆的定时炸弹**。

## 核心分析与要点

- **核心内容**：Ultra Mobile PayGo 前身是 T-Mobile 的 $3/月套餐，2019 年转由 Ultra Mobile 运营，是目前月租最低的美国原生实体卡。套餐为每月 $3，含 100 分钟美国通话、100 条短信、100MB 美国流量（仅本土可用）。全文 16 节：这张卡是什么 → 去哪买 → 激活 SOP → 充值三法 → 激活后必做清单与保号 → Wi-Fi Calling 原理 → 设置教程 → 排障 → 接码能力 → 2025 封号潮 → eSIM 转换 → 欠费救号 → 补卡 → PayGo vs Tello → 进阶玩法 → 附录速查。

- **关键亮点 / 结论**：
  - **Wi-Fi Calling 是总开关**：套餐额度只在美国本土生效，不开启 Wi-Fi Calling 就全部按国际漫游计费——接打电话 $3.59/分钟、收短信 $0.1/条、发短信 $0.5/条、流量 $0.03/MB。作者的原话是"没开 Wi-Fi Calling 的 PayGo，约等于一张随时在爆炸的定时炸弹"。
  - **封号潮是这份文档最有价值的部分**：2025 年 2 月起，大量在国内激活的 PayGo 在 1–2 天内被封（无信号、无法登录官网），且**基本无法恢复**。原因指向 Ultra Mobile 开始识别并限制中国大陆 IP 激活的账号，部分代激活卖家用国内 IP 批量激活，风险更高。应对是：激活走美国住宅 IP（别用机场共享 IP）、优先携号转网、激活后立刻完成 Wi-Fi Calling 建立正常使用记录。
  - **与 Google Voice 的本质差别**：GV 是虚拟号，Wells Fargo 短信验证、PayPal 新设备加号、Zelle 注册等场景会被直接拒绝；PayGo 是实体号，因而能过这些金融类校验——这也是很多人从 GV 换过来的真实原因。
  - **保号逻辑与欠费窗口**：$3/月强制扣款，余额归零即断号（与 giffgaff 的 0 月租 180 天保号完全不同）；零余额仍能维持基础信号，但累计欠费达 60 天永久停机，中间是 60 天救援窗口。作者建议开自动续费、余额常年留 $5 以上缓冲。
  - **排障方案给了三条**：Wi-Fi Calling 在国内不稳是因为 T-Mobile 的 ePDG 域名被干扰，可分别用代理规则（`IP-CIDR,208.54.0.0/16` 与四个 `epdg` 域名）、路由器 DNS 规则、境外流量卡热点三种方式解决；另外接码时务必关 VPN，否则会按漫游扣费而不是走套餐。
  - **急救清单很具体**：补卡自 2025 年 3 月起可办（官网充 $13、客服 3 个工作日处理、仅寄美国地址，转运约 $40 且耗时约 1 个月）；国内丢卡更快的办法是转 eSIM；联系客服前要备好最近 5 个通话号码、登记姓名与美国地址、绑定邮箱、信用卡后四位、Wi-Fi Calling 的 911 地址、最近三次充值记录。
  - **PayGo vs Tello 的取舍清楚**：PayGo $3/月但必须配 Wi-Fi Calling；Tello $5/月、免配置、短信不限量、100 分钟含 60+ 国家（含中国）。只接码不打电话选 PayGo，要打电话或不想折腾选 Tello。

- **适用场景 / 启发**：
  - 需要长期维持一个美国 +1 号来收银行、券商、PayPal、Apple ID 与 AI 服务验证码的人，这份文档基本可以当操作手册用。
  - 对做跨境账号体系的人，它揭示了一个关键点：**"能不能收码"取决于号码类型（实体 vs 虚拟）与使用记录（是否建立正常的本地用量）**，而不只是"有号"。
  - 使用前的三点提醒：其一，封号是系统性风险而非个例，且政策随时变化，资费与规则**以 Ultra Mobile 官方页面为准**；其二，文中含作者自己的 giffgaff 卡售卖与推广，属商业内容；其三，用境外号码注册金融服务、接码转码涉及各国实名与合规要求，风险自行承担。
