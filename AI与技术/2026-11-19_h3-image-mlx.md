# h3-image-mlx

## 一句话摘要
> 在 Apple Silicon 上用 MLX 跑 MiniMax H3 图像生成与编辑，4K 出图峰值内存约 7GB。

## 核心分析与要点

- **核心内容**：把 MiniMax H3 Image 的生成与编辑搬到 Mac 本地，用 MLX 做推理优化，提供 CLI 与 Python API 两种入口。
- **关键亮点 / 结论**：
  - 内存是重点优化目标：4K 生成峰值约 7GB，说明做了分块/流式加载，而不是整模进显存。
  - README 给了可核对的加速数据：M5 Pro 上 1024×1024 从 26.49s 降到 18.93s（0.1.0a8，W8A8 常驻）；M4 Pro 上从 250.55s 降到 101.56s（0.1.0a9，INT8 分块 Metal 投影）。
  - 按芯片代际给出不同后端（M1–M4 用 portable、M5 用常驻 W8A8），属于比较务实的适配策略。
- **适用场景 / 启发**：Mac 用户想本地出图又不想上云；也可作为「diffusion transformer 在 MLX 上量化 + 分块推理」的工程参考。
