# DSH插件市场

## 一句话摘要
> DeepSeek Harness 的社区插件索引站：把 1294 个社区插件按 11 类归档，提供一个可直接粘进 DSH「发现」页的 `index.json`，并每 6 小时轮换推荐——不唯 star 论，刻意给小开发者曝光。

## 核心分析与要点

- **核心内容**：站点做两件事——一是**索引**：`https://dshopen.org/index.json` 作为 DSH「自定义插件市场」的索引源，粘进去就能在 DSH 内浏览、搜索、安装；二是**展示**：网页端按分类、点赞、星数、近期增长、最近更新等维度排序，附插件名、版本、适用 DSH 版本区间与发布时间。

- **关键亮点 / 结论**：
  - **推荐机制是它的差异化**：默认排序每 6 小时轮换，权重偏向"最近增长快、更新勤"，同时参考验证、下载量、star 与点赞，并明确"同一作者不会霸榜"——这是对插件市场常见"强者恒强"问题的一个刻意设计。
  - **两行命令即可接入**：`dsh plugin --profile desktop add dsh-open-market` 会自动打开「自定义插件市场」、加入索引，并在插件页生成「开放市场」标签；也可以走界面手动添加索引源。
  - **分类规模清楚**：界面 244、工具 232、开发与运维 135、工作流与协作 131、集成 128、模型供应商 104、用量与费用 91、外观 89、记忆 60、技能 52、知识与研究 28，合计 1294 个。
  - **边界划得很清楚**：站内 FAQ 与本页页脚都写明"独立的社区项目，与 DeepSeek 官方无隶属关系"，并提示"发布包检查不等于安装测试或代码审计"——这类免责声明对插件市场是必要的，也提示安装前仍需自行判断。

- **适用场景 / 启发**：
  - 已在用 DSH 的人可以把这个索引加进去，直接把"找插件"从 GitHub 搜索变成站内浏览；分类里的「记忆」「用量与费用」「工作流与协作」是官方市场里不容易一眼看清的细分。
  - 对做生态索引的人是个样本：用官方支持的索引格式接入、把推荐算法当作产品卖点、给收录者提供可嵌入的徽章，形成"提交—展示—引流"的闭环。
  - 需要留意：页面上的点赞、星数等是**站点自行采集的快照**，且索引每 6 小时才更新一次；插件是否可信仍取决于源码与作者，站点明确表示不做代码审计。

**它是什么**

> DeepSeek Harness 的社区插件索引与每日推荐。10 月 15 日起 DSH 支持插件市场，复制下面的地址粘贴到「发现」，就能直接浏览、安装几百个社区插件。

> 开放插件市场（dshopen.org）是社区维护的 DSH 插件市场，也就是 DeepSeek Harness 的开放插件索引：免费使用，任何人都可以提交插件。目前收录 1294 个插件，附中英文简介、版本、下载量和维护者审查记录，每 6 小时更新一次，可以直接在 DSH 的「发现」页里使用。本站是独立的社区项目，与 DeepSeek 官方无关。

**怎么装**

> 方法一：在「插件 → 实验性插件」中打开「自定义插件市场」，再到「发现 → 添加索引源」粘贴索引地址，然后在「发现」里搜索插件名并安装。方法二：运行 dsh plugin --profile desktop add dsh-open-market，它会自动完成上面的设置，并在「插件」页加一个「开放市场」标签。

**推荐怎么排**

> 默认推荐每 6 小时轮换，以最近增长快、更新勤的插件为主，同时参考验证、下载量、star 和点赞。同一作者不会霸榜，新项目和小开发者的作品也有机会上首屏。

**与官方的边界**

> 开放插件市场是独立的社区项目，与 DeepSeek 官方无隶属关系。它使用 DSH 官方插件市场支持的索引格式，插件由 DSH 自己下载和安装。

**收录方式**

> 在 GitHub 上填写收录申请，提供公开源码、npm 包和许可证即可。收录后可以在 README 放上徽章，显示点赞数并链接到本站的插件页。

**风险提示（页脚）**

> 独立社区项目。 发布包检查不等于安装测试或代码审计。安装时，DSH 会检查版本兼容性。
