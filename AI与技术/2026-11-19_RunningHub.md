# RunningHub

## 一句话摘要
> 把 ComfyUI 工作流搬到云端跑的商业化 AIGC 平台：一键跑复杂工作流出图出视频，同时把同一套能力包成 AI 应用、模型与人像 API 卖给开发者，外加短剧工具与邀请裂变。

## 核心分析与要点

- **核心内容**：站点自我定位为"原生 AI 智能体驱动的全能内容创作平台"，主打四类能力：**ComfyUI 工作流**（上传/运行复杂节点图，不必自备显卡）、**无限画布**（rhTV）、**AI 应用与 Skill**（快捷创作 Runow、VibeX 智能开发）、**模型与 API**（LLM / 模型 / AI 应用 / 工作流四类 API）。产品矩阵还包括 RHSTORY 短剧漫剧平台、Labs、创作学院与模板市场。

- **关键亮点 / 结论**：
  - **"ComfyUI 上云 + API 化"是它的核心生意**：对个人是把本地跑不动的工作流搬到云上按次付费；对开发者是把同一套工作流封装成 HTTP 接口，直接嵌进自己的产品。这两端共用一套算力与模型，边际成本结构清晰。
  - **产品线铺得很开**：视频生成（Seedance 2.5 Flash）、图像生成（Seedream 5.5，提到图层拆分与透明背景）、视频超分（RH Upscale）、短剧漫剧（RHSTORY 2.0，含角色、剧本、智能分镜）、电商模板（UGC 广告、模特试穿、服装展示）。页面上的模板都带播放量标注（如 182w、200w），说明它是按"能不能出爆款"来组织内容的。
  - **商业化组合是会员 + 用量 + 裂变**：会员按时段折扣（页面写"每日 00:00–10:00 会员 5 折｜并发上限 3 个"）、按模型计费（指定会员低至 ¥0.10/秒）、邀请返利（邀新争霸赛、邀请好友享折扣）、以及创作者激励计划（有收益排行榜）。这是典型的"算力平台"增长模型。
  - **运营主体与资质是公开的**：页脚列出安徽海马云智能科技发展有限公司、ICP 备案、网信算备、增值电信业务经营许可证与公安备案，属于合规信息较完整的商业平台。

- **适用场景 / 启发**：
  - 本地显卡不足、又想跑 ComfyUI 复杂工作流的，可以用它替代自建；做电商图/短视频批量的，模板库能直接起步。
  - 开发者可以关注它的四类 API——把现成工作流当"函数"调用，比自己部署模型省事，但要评估按次计费在高并发下的成本。
  - **注意**：这是**闭源商业平台**而非开源项目，页面信息以营销位与活动为主（限时折扣、邀请奖励随时变化），实际价格与并发限制以站内当期页面为准；生成内容的版权归属与商用授权需按平台服务协议确认。
