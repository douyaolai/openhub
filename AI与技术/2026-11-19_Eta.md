# Eta

## 一句话摘要
> Android 系统级 AI Agent：越过沙盒直接读写系统与厂商应用，能管日历闹钟便签，也能翻相册查验证码。

## 核心分析与要点

- **核心内容**：面向 Android 的第三方系统级 AI 助手，目标是对标手机厂商预装的一方助手——不是靠无障碍模拟点击，而是直接调用 Android API 与厂商应用原生接口。
- **关键亮点 / 结论**：
  - 个人上下文极深：系统 Provider、ColorOS DMP 索引、小布记忆 Hook 桥，可检索位置、通知历史、使用统计、日历、相册（含图片文字与画面检索）、通讯录、短信验证码、通话记录、录音摘要、健康汇总、剪贴板、账单行程等。
  - 系统操作带读回核验：改日历、闹钟、便签、手电筒、亮度、勿扰、音量、Wi-Fi、蓝牙、NFC、应用冻结后都会复查状态。
  - 自研 Agent Runtime 与 Agent Loop，支持 Skills 与 MCP；模型可 BYOK，也能用 Codex（ChatGPT）或 Grok 订阅登录。
  - 可替换系统默认数字助理，长按电源键唤醒并自动附带当前屏幕内容；支持一圈即搜、状态胶囊与锁屏实时活动。
- **适用场景 / 启发**：想要"真·手机助理"的 Android 高级用户。必须清楚：它需要 Root/LSPosed 或特定 ROM，权限极大，等于把手机控制权交给模型，务必在理解风险后使用。

> 不同于仅停留在无障碍模拟点击或通用 Root Shell 的第三方 Agent，Eta 对标的是手机厂商预装的一方系统助手。项目针对 Android 系统服务与厂商一方应用做了大量深度适配，目标是提供真正的**系统级 AI 助手体验**：

> Eta 独立实现了 Agent Runtime 与 Agent Loop，统一编排模型调用、工具执行和结果反馈，并支持 Skills 与 MCP 扩展。使用 AI 功能支持自备模型服务的 **API Key（BYOK）**，也支持 **Codex（ChatGPT）与 Grok 订阅账号登录**，模型与服务商由你选择。

> 支持 **Android 13 及以上版本的 ARM64 设备**，App 本体不限手机品牌，基础功能无需 Root。Root 和 LSPosed 可进一步开放深层个人上下文、一方应用接口与系统助手入口，具体能力取决于授权和 ROM 适配。
