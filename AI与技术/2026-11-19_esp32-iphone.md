# esp32-iphone

## 一句话摘要
> 用 7 美元的 ESP32 让 AI 直接操作真机 iPhone：AirPlay 当眼睛、USB HID 当手，不用越狱也不要开发者账号。

## 核心分析与要点

- **核心内容**：一块 ESP32-S3（如 Seeed XIAO）接在 Mac 上，同时充当 AirPlay 投屏接收端（看到屏幕）与 USB HID 设备（模拟触摸/键盘），再配一个 iOS App，让视觉模型看着屏幕操作真机。
- **关键亮点 / 结论**：
  - 成本与门槛都压到极低：7 美元硬件 + 任意 OpenAI 兼容视觉模型，不需要 Mac 跑模拟器、不需要开发者账号、不需要越狱。
  - 演示里 AI 自己完成了 Duolingo 课程，甚至能自主打电话——说明它的操作粒度已到"GUI 级"。
  - 提供 MCP server 与 DSH 插件路径，可被编码 agent 调用。
- **适用场景 / 启发**：手机 GUI Agent 的研究与演示；也是「用廉价硬件补齐 agent 感官与执行器」的典型思路。需要购买硬件并刷固件，属于动手项目。
