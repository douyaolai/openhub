# Claude防封号与订阅指南

## 一句话摘要
> 一篇 6800 字的实操长文：先讲怎么让 Claude 账号一年不被封，再讲国内如何办一张新加坡卡，最后把订阅时的顺序和容易踩的坑一步步走出来——核心主张只有一条：**订阅国、网络出口、账单地址、发卡地必须始终是同一个国家**。

## 核心分析与要点

- **核心内容**：作者自述账号注册 1 年 2 个月零封禁、同时持有 200 美元的 Max 与 Team 账号，把经验拆成三部分：防封号（网络与客户端配置）、办卡（新加坡 Starryblu）、订阅（切区与下单顺序）。文中给出了具体配置路径、端口常见的 7897、含税价格换算，以及一张可查证的牌照信息。

- **关键亮点 / 结论**：
  - **一致性高于"纯净度"**：作者的经验是同一国家内换出口（多个新加坡出口来回切、或自建新加坡机器）都没出事，跨国家换出口才是真风险；他明确说"很多人花大价钱去追所谓的纯净住宅 IP，方向错了"，并点名大陆与香港不要用。
  - **Claude Code 与 Claude App 是两条网络路径**，这是全文最实用的一段：前者可在 `~/.claude/settings.json` 单独指定出口；后者是 Electron 应用，不一定会读 `.zshrc` 里的环境变量，且长期挂后台同步，休眠/切 Wi-Fi 后尤其容易走错线路。验证方法是看网络软件的连接记录、搜 `claude`、`anthropic`，而不是只看"已连接"。
  - **明确的负面清单**：不授权第三方客户端或插件、少用 `claude -p` 做脚本化批量调用、不做任何反代中转；也不建议在手机上用 Claude。
  - **办卡部分讲清了易被误传的一点**：Starryblu 给的**不是 OCBC 个人银行账户**，而是同名收款信息，客户资金托管在 OCBC 的监管账户；托管≠存款保险，新加坡存款保险只保银行储户。运营主体是 WoTransfer Pte. Ltd.（UEN 201941244H），持 MAS 大型支付机构牌照 PS20200501，与熊猫速汇同门。
  - **税费是最容易算错的一步**：新加坡区含 GST，Pro 含税 30 新币/月（约 23.5 美元）、Max 5x 150 新币（约 118 美元）、Max 20x 300 新币（约 235 美元）；只充 200 美元去扣 Max 20x 会失败。作者自己也不建议用美国免税州地址，理由是账单地址与网络对不上是不愿在主力账号上冒的险。

- **适用场景 / 启发**：
  - 适合正在长期使用 Claude 且希望账号稳定的人，尤其是同时用 Claude Code 与桌面客户端的；网络分层那一段可以直接对照自查。
  - 对做跨境订阅的人，文中"提现占结汇额度、扫码消费走跨境通道不占额度"的区分有参考价值（作者注明以银行与外汇管理部门规定为准）。
  - **阅读前须知两点**：其一，这是**带推广的长文**，文中含专属邀请码与返利链接，作者也自行披露了；其二，账号风控与跨境支付都涉平台条款与当地法规，文中做法不保证有效，风险由使用者自负。

**一致性这一条**

> 这是我唯一一条从不妥协的规则。订阅区是新加坡，网络是新加坡，账单地址是新加坡，卡也是新加坡的，从注册第一天到今天没变过。

> 风控看的不是你在哪个国家，是你说的和做的一不一致。

**关于 IP 纯不纯净**

> 两种都跑了很长时间，账号都没有异常。所以我的判断是：同一个国家里换出口，影响很小；跨国家换出口，才是真的危险。很多人花大价钱去追所谓的纯净住宅 IP，方向错了。

**两条网络路径**

> 实际上不是。

> Claude Code 和桌面客户端读取网络配置的方式并不完全一样。

**桌面版为什么不一定会读环境变量**

> 桌面版 Claude 是 Electron 应用，和终端程序的网络继承方式不完全一样。

**负面清单**

> - 不要把账号授权给任何第三方客户端或者插件

> - 少用 claude -p，脚本化的批量调用最像中转站

**OCBC 账户的误传**

> 网上很多教程写成：护照免费开新加坡 OCBC 银行账户。这个说法不准确。你拿到的不是一个能登录 OCBC 网银的个人银行账户，而是 Starryblu 给你开的收款信息，客户资金托管在 OCBC 的监管账户里。你能收钱，能用这个账号做同名转账，但你不是 OCBC 的储户。

> 托管不等于存款保险。 新加坡的存款保险只保银行储户，你不是储户，你走的是支付服务法要求的资金隔离存管，是另一套机制。所以这张卡当支付通道用就好，别把钱囤在里面。

**账单地址的选择**

> 这一步是我和网上很多攻略不一样的地方。很多教程会教你填美国免税州的地址来省掉税费。我不这么做。新加坡有 GST，填新加坡地址意味着 200 刀的账号每个月多付 35 刀左右。我认这笔钱很值。

**作者自己的风险提示**

> 第一是不是银行。MAS 牌照管的是支付合规，不含存款保险。大额长期趴在任何电子钱包里都不明智。

> 第三是合规。资金来源、用途、居住地、当地法规，这些都是你自己要负责的。工具合规不等于用法合规。
