# Kun

## 一句话摘要
> 本地优先的 AI 桌面工作台：写代码、做设计、处理文档共用一个 runtime，会话与记忆留在本机，模型自己接。

## 核心分析与要点

- **核心内容**：Code / Design / Work 三个场景共用一个本地运行时，任务可以分派给不同 Agent 协作完成；会话、记忆与设置保存在本机，模型通过 OpenAI/Anthropic 兼容接口或本地模型接入。
- **关键亮点 / 结论**：
  - Design 画布先比较多屏方案再交给 Agent 实现，这个「先看方案再动手」的交互比直接让 agent 写代码更可控。
  - 多 Agent 协作做得细：可与个人 Agent、Codex、Claude Code、OpenCode 私聊或拉群，为计划选择执行 Agent 并查看各自进展。
  - 扩展面广：MCP / Skills、Loops、Extension 平台，以及 GitHub/Gmail 连接、定时任务、终端 TUI、手机远程。
- **适用场景 / 启发**：对数据本地化敏感、又想要多 agent 协作的个人开发者。它更像"工作台"而不是"编码助手"，适合把写作、设计、研究也放进同一个上下文。

> Kun 是跑在你电脑上的桌面应用。Code、Work 和对话共用一个本地运行时：写代码、做设计、处理文档和论文，也能把任务交给不同的 Agent 协作完成。会话、记忆和设置留在本机，模型由你自己接入。

> 还有：提醒与定时任务、存储管理、终端 TUI、手机远程、Kun 账号与衣橱。最新变化见 [0.4.4 更新日志](release/release-v0.4.4.md)。

> Linux 的 `.deb` 请用 `sudo apt install ./Kun-*.deb` 安装，apt 会一并装上 `libnotify4` 等依赖；`dpkg -i` 不处理依赖，在精简系统上会装不上。
