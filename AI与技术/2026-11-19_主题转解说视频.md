# 主题转解说视频

## 一句话摘要
> 给个主题就出解说视频：黑底动效、TTS 配音、字幕、章节进度条，每一帧都用 Remotion 代码画出来。

## 核心分析与要点

- **核心内容**：一个 Claude Code / Codex 的 skill，把任意主题做成中英双语的动效解说片。产物是 Remotion（React + TypeScript）工程，画面全部由代码绘制，不使用素材库、不使用生成式视频模型。
- **关键亮点 / 结论**：
  - 交付的不是脚本而是「整套方法」：可编译的 Remotion 模板、图元与光照库、配音/分镜/渲染/量化质检工具、风格与动效规范、多 agent 分工协议，以及一部参考成片作为质量基线。
  - 有明确的成片规格：英文版 5′02″、44 行 785 词，中文版 4′54″、44 行 1490 字——说明它把"多长、多少行"也标准化了。
  - 用代码画帧的好处是可复现、可微调，不存在素材版权问题。
- **适用场景 / 启发**：知识科普类短视频的批量生产；也适合研究「agent skill 如何封装一条完整生产流水线」。需要 Node 环境与 Remotion 渲染能力。
