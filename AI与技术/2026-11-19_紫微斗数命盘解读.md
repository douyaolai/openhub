# 紫微斗数命盘解读

## 一句话摘要
> 紫微斗数命盘 skill：Python 精确排盘 + 规则引擎判格局 + AI 写解读，输出双主题可视化 HTML。

## 核心分析与要点

- **核心内容**：一个给 Claude Code / Codex 用的 Agent Skill。输入生辰信息后，先用 `iztro-py` 精确排盘，再由确定性规则引擎判格局，最后让模型生成解读，产出带配色的 HTML 命盘。
- **关键亮点 / 结论**：
  - 关键设计是「算的部分不由 LLM 做」：排盘与格局判定交给 Python 与规则，模型只负责措辞，README 专门有一节解释为什么不直接让 LLM 算。
  - 方法论上是紫微三合派 + 中州派 + 手相互证的混合，V2 增加了宏观格局仪表盘、大限、时空压力（化忌叠冲）热力表。
  - 输出为双主题 HTML，可直接分享或存档。
- **适用场景 / 启发**：想在 AI 客户端里做命理解读的人；也是一个「确定性计算 + LLM 表达」混合架构的干净样例。注意命理属于传统文化与娱乐范畴，不构成任何预测或决策依据。
